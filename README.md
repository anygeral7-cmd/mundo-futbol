# Mundo Fútbol ⚽

## Descripción

Mundo Fútbol es un sitio web educativo dedicado al mundo del fútbol. El sitio fue desarrollado como parte de una práctica escolar de diseño y desarrollo web.

## Contenido del sitio

El sitio web incluye información sobre:

- Historia del fútbol
- Reglas principales
- Posiciones de los jugadores
- Jugadores destacados
- Equipos famosos
- Datos y curiosidades del fútbol

## Objetivo

El objetivo del proyecto es presentar información sobre el fútbol de una manera moderna, atractiva y fácil de navegar.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Diseño

El sitio cuenta con un diseño moderno y juvenil, utilizando una combinación de colores relacionados con el fútbol y una estructura adaptable para facilitar la navegación.

## Autor

Proyecto realizado como práctica escolar.
